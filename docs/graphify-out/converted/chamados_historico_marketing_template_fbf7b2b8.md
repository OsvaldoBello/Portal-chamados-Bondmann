## Sheet: Instruções
| Histórico de Chamados do Marketing — Modelo de Preenchimento |
| --- |
| Este arquivo serve para levantar as demandas antigas do Marketing (que ainda não estão no Portal de Chamados) para que sejam importadas de forma organizada e os indicadores fiquem completos.

Preencha uma linha por chamado/demanda na aba "Chamados (preencher aqui)". Depois de preenchido, envie o arquivo de volta para que os chamados sejam cadastrados no Portal. |
| Como preencher |
| •  Campos com * na aba de preenchimento são obrigatórios; os demais, preencha quando souber. |
| •  Não altere o cabeçalho nem a ordem das colunas — isso facilita a importação. |
| •  Colunas com seta de seleção (Categoria, Setor, Status, Prioridade, Origem da Demanda, Causa do Atraso, Avaliação) têm uma lista pronta: clique na célula e escolha uma opção. |
| •  A coluna "Subcategoria" depende da Categoria escolhida — consulte a tabela de referência na aba "Legenda" para ver quais subcategorias existem para cada categoria. |
| •  Datas: use o formato dd/mm/aaaa (ex.: 15/03/2026). Se não souber uma data exata, deixe em branco. |
| •  "Solicitante" é quem pediu a demanda (nome ou e-mail); "Responsável" é quem do Marketing executou/atendeu. |
| •  "Volume" é a quantidade de itens da demanda (ex.: 3 peças, 5 e-mails) — use 1 quando não se aplicar. |
| •  "Status" descreve a situação atual: use RESOLVIDO para demandas já entregues (a maioria do histórico). |
| •  Se a demanda já foi entregue com atraso, preencha "Causa do atraso" — ajuda o indicador de motivos de atraso. |
| •  Pode adicionar quantas linhas precisar; a formatação e as listas de seleção já se estendem pelas linhas prontas (150 linhas). |
| Dúvidas |
| Qualquer dúvida sobre o preenchimento, fale com o time de TI responsável pelo Portal de Chamados. |
